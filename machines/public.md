# This machine: public (any OS), personal

- The harness install folder is your clone of the repository, at a path of your choosing (`~/claude-harness` is the convention the README uses). Update it with `git pull` and `python install.py --machine public`; a release replaces the shared files and never touches your local files.
- Shell: on Windows, Windows PowerShell 5.1 has no `&&` or `||`, no ternary and no null-conditional; chain with `;` and `if ($?) {}`. Bash syntax runs through the `!` prefix in Git Bash, where MSYS path mangling applies. On macOS and Linux the default shell needs no special care.
- Python: `python` or `python3`, 3.11 or newer; the interpreter that runs install.py is the one written into the hook commands.
- Codex CLI is optional here. The Codex-first rule (Codex implements, Claude orchestrates) and its guard hook stay off until /setup records that Codex is installed and logged in; the local file imported next says which applies. Without Codex, Claude edits directly and the delegate, auto and verify-pass skills are not used.
- Context save nudge hook (PostToolUse): asks once for a handoff save past context_save_at tokens from machine.json (default 150000, 0 disables), again after 15 minutes without a handoff write, once per further threshold of growth after a save, and after each compaction.
- Windows only: Alt+V image paste fails silently on some Claude Code builds (upstream issue 59661); run `! powershell -NoProfile -ExecutionPolicy Bypass -File "<install folder>/tools/clip_image.ps1"` (the quotes and forward slashes are for the Git Bash shell behind the `!` prefix) from the prompt, with the command typed first and the image copied last, and the saved image path lands in the conversation and on the clipboard. The harness merges ~/.claude/keybindings.json with the Alt/Option+V chord; existing bindings are kept.
- Where the permission classifier blocks config edits under ~/.claude, run install.py with the `!` prefix inside a Claude session.
- Your own facts live in the local file imported next (machine.local.md, never committed, never overwritten by an install): the Who I am paragraph, your git identities, your Codex answer. The first install writes it as a stub with the section to fill; /setup fills it by asking.
